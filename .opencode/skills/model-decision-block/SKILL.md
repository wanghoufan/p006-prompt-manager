# 模型决策块 — 硬性格式（中文）

> 来源：`~/.workbuddy/AI_MODEL_GUIDE.md:8` Stage Manager 强制约定。非排序清单，各厂商行均为并列可选。

## 硬性格式（必须原样）

```text
当前任务：<S/A/B/C>｜<前端/软件工程/Agent/文档/视觉等 任务侧写>

符合模型：
- <厂商>：<精确模型 ID> / <思考强度>｜开发成本：<低/中/高>｜<任务侧写>
...
- <厂商>：暂无合格型号｜原因：<证据或稳定性原因>
```

## 规则

- 对该等级下的每一家厂商（OpenAI、Anthropic、Moonshot AI、Google、xAI、阿里/Qwen、Z.AI）必须各输出一行；不得用“等等”“同上”或笼统等级代替。
- 仅输出指南中标记为“自动推荐”的模型；ID、思考强度、成本档必须逐字照搬指南。
- 若某厂商在该等级无合格型号，仍需输出“暂无合格型号｜原因：…”。
- 不得输出“主推/备选/第一名”等排序措辞；各行均为并列。
- 模型块必须出现在 **当前唯一执行 Prompt 之前**。

## 任务等级映射

- S：最复杂核心开发 / 长程 Agent
- A：复杂功能与审查
- B：常规功能、修复、测试
- C：轻量文档、整理、低风险改写
