# 用户反馈 P0 — 最高优先级（中文）

> 适用：任何用户口头反馈或截图反馈的产品体验问题（标签、搜索、界面等）。

## 规则（2026-08-27 用户确认）

用户反馈为 **P0 最高优先级**，高于一切 P1/P2/P3，必须立即记录并排入下一轮 `PLAN`。

## 操作步骤

1. 写入 `docs/review/PRODUCT_BACKLOG.md` 的 `## P0 用户反馈（最高优先级 · <日期>）` 段，置于 `## P1` 之上：
```md
### P0-N <标题>（<日期> 用户截图/口述）
- 问题：<文件:行号> + 截图描述
- 用户场景：<逐字用户场景，含截图路径>
- 为什么是问题：<影响>
- 建议方案：<文件路径 + 逻辑>
- 预期收益：<收益>
- 实现成本：低/中
- 优先级：P0（用户反馈最高）
```
2. 在 P0 段顶部加入规则块：
> 规则：此 P0 段为**最高优先级**，高于一切 P1/P2/P3；后续新增用户反馈均置顶于此，进入当前 PLAN 即时排期。
3. 下一轮 `PLAN` 必须优先包含 P0 项；不得将内部技术债排在用户反馈之前。
4. 不得全量搜索历史来重复验证已 CLOSED 事项；新反馈按新 P0 记录。

## 违规示例

- 将用户反馈记为 P2/P3 或 Future
- 将 P0 推迟到后续里程碑，先做内部 polish
