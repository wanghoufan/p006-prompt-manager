# 提示词管理工具 — 需求文档（PRD）

> 版本：v1（第一版）
> 日期：2026-08-15
> 状态：需求已确认，待开发

---

## 1. 项目概述

一个**本地网页端**的提示词管理工具。用户把提示词正文粘贴进来进行集中管理，AI 自动补全标签与标题；使用时点击「复制」即可取出，并自动累计复制次数，帮助用户判断哪条提示词真正有用。支持打星评分、按复制次数/评分排序、正文版本管理（可回滚）、思维方式总结，以及全量导入导出备份。

## 2. 技术栈与架构

| 项 | 决策 |
|---|---|
| 框架 | **Next.js（App Router）**，`npm run dev` 跑在 localhost |
| 语言 | TypeScript + React |
| AI 模型 | **DeepSeek `deepseek-v4-flash`**（OpenAI 兼容接口） |
| AI 调用方式 | 服务端 API 路由代理，密钥不暴露到浏览器 |
| 数据存储 | **浏览器 localStorage**（键名如 `prompt-manager`） |
| 样式 | 自选（Tailwind CSS 或纯 CSS），不强制 |

**架构要点**：DeepSeek 调用必须走服务端（Next.js Route Handler），前端通过 `fetch` 调本地 API 路由；`DEEPSEEK_API_KEY` 只存在于 `.env.local`，绝不出现在前端代码或打包产物中。

## 3. 页面布局与交互

### 3.1 整体布局
- **左侧**：标签面板，从上至下排列标签列表。
- **右侧**：提示词卡片展示区。

### 3.2 标签面板
- 标签由 AI 生成，面板**去重聚合**显示所有已存在的标签。
- **单选筛选**：点一个标签 → 右侧只显示该标签下的卡片；再点同一个标签 → 取消，回到「全部」。
- 面板顶部提供「全部」入口，显示卡片总数。

### 3.3 卡片列表态（精简信息）
每张卡片显示：标题、标签、星级、复制次数、「复制」按钮。
- 点卡片（除控件外）→ **选中**（高亮），作为键盘打星的目标。
- 点卡片 / 「编辑」→ 进入**详情/编辑视图**。

### 3.4 详情/编辑视图
点卡片进入（用模态框实现），包含：
- 完整正文展示与编辑（`textarea`）
- 标题、标签展示（可手动编辑，可选）
- 星级、复制次数、「复制」按钮
- 「保存」按钮（正文变化时生成版本）、「复制次数清零」按钮
- 版本历史列表 + 回滚
- 「思维方式总结」按钮及其结果

## 4. 数据模型

### 4.1 卡片（Card）
```json
{
  "id": "uuid",
  "title": "一句话总结（AI 生成）",
  "body": "提示词正文",
  "tags": ["标签1", "标签2"],
  "rating": 0,
  "copyCount": 0,
  "thinkingSummary": null,
  "versions": [],
  "createdAt": "2026-08-15T10:00:00.000Z",
  "updatedAt": "2026-08-15T10:00:00.000Z"
}
```

字段说明：
- `rating`：`0` 表示未评分（清除状态）；`1~5` 为星级。
- `copyCount`：复制次数，仅点「复制」按钮时 +1。
- `versions`：版本数组，见 4.2。
- `thinkingSummary`：思维方式总结结果（`null` 表示尚未生成）。

### 4.2 版本（Version）
```json
{
  "id": "uuid",
  "body": "该版本的正文快照",
  "createdAt": "2026-08-15T10:05:00.000Z"
}
```
- 仅记录**正文**快照；标签/标题/评分/复制次数不参与版本。
- 最多保留 **10 条**，超出时淘汰最旧（FIFO）。

### 4.3 设置（Settings，localStorage 单独键）
```json
{
  "thinkingSummaryPrompt": "（思维方式总结的自定义提示词模板，可覆盖默认模板）"
}
```

## 5. 功能需求

### 5.1 输入与 AI 自动生成标签/标题
- 用户**只输入正文**（粘贴到输入框）。
- **粘贴后全自动触发**：检测到粘贴事件，调用 AI，一次性返回「标签 + 标题」。
- 标签生成策略：**自由生成 + 强制约束**——每个标签 2~4 字、语义简短、**优先复用已有标签**（把当前已存在标签列表作为上下文传给 AI），每张卡 1~3 个标签。
- 自动生成只在「创建卡片时粘贴」触发；之后**编辑正文不自动重跑 AI**（避免乱改标签/标题），如需重生成另设手动入口（详情视图内「重新生成标签/标题」按钮）。
- 标题（一句话总结）不超过 20 字。

### 5.2 复制与复制次数统计
- 卡片上有一个明确的「复制」按钮。
- **点「复制」按钮**：把正文写入剪贴板，`copyCount += 1`。
- 点卡片其他区域**不**触发复制（避免误触）。
- 复制次数在卡片上实时显示，用于判断该提示词是否被高频使用。

### 5.3 评分（打星）
- 每张卡支持 1~5 星。
- **键盘**：选中某张卡后，按 `1`~`5` 打对应星级；按 `0` 清除评分（`rating = 0`）。
- **鼠标**：卡片/详情上的星标可直接点击打星。
- 键盘目标为「当前选中（高亮）的卡片」；详情视图内作用于正在查看的卡。

### 5.4 排序与筛选
- 排序：按**复制次数降序**，或按**评分（星级）降序**；另保留默认（按创建/更新时间）。
- 排序作用于**当前展示的集合**：未选标签时全局排序；选中某标签时在该标签内排序。

### 5.5 版本管理
- **触发**：显式「保存」动作（详情视图内的保存按钮，或 `Ctrl/Cmd + Enter`）——仅当**正文有变化**时，生成一个新版本快照。
- 每条卡最多 **10 个版本**，超出淘汰最旧。
- **回滚**：版本历史中任选一条 → 正文恢复为该版本内容，**并新增一条版本记录**（回滚本身也可被再次回滚，历史保持线性）。

### 5.6 复制次数清零
- 详情视图内提供「复制次数清零」按钮，单卡复制次数重置为 `0`（便于测试复制统计功能）。

### 5.7 思维方式总结
- 详情视图内提供「思维方式总结」按钮。
- 点击 → 调用 AI，按「思维方式总结提示词模板」总结该提示词的思维方式，结果**缓存在该卡的 `thinkingSummary` 字段**，可重新生成。
- **预设模板**：见 6.3。
- **自定义**：设置里可修改该模板（存 localStorage），达到更好效果。

### 5.8 导入导出（备份管理）
- **导出**：JSON 文件，包含全部卡片数据（正文、标题、标签、星级、复制次数、版本历史、思维方式总结、时间戳）与设置。
- **导入**：选择 JSON 文件 → **整体恢复**（弹确认框，覆盖当前数据）。
- 导入后对数据进行基本校验（结构合法、字段类型正确）。

## 6. AI 集成（DeepSeek）

### 6.1 模型与接口
- 模型：`deepseek-v4-flash`
- 接口：OpenAI 兼容 `POST {base_url}/chat/completions`，base_url 默认 `https://api.deepseek.com`（亦支持 `/v1` 前缀）。
- 鉴权：`Authorization: Bearer <DEEPSEEK_API_KEY>`。

### 6.2 服务端 API 路由
- `POST /api/ai/generate-meta` → 入参 `{ body, existingTags }`，返回 `{ title, tags }`。
- `POST /api/ai/summarize-thinking` → 入参 `{ body }`，返回 `{ summary }`。
- 两条路由均读取 `process.env.DEEPSEEK_API_KEY`，失败时返回统一错误信息，前端做加载态与错误提示。

### 6.3 预设提示词

**（1）标签/标题生成（内部固定，暂不开放自定义）**
```
你是提示词分类助手。用户会给你一段提示词正文，请：
1. 生成一个「一句话总结」作为标题，不超过 20 个字，概括这条提示词的用途。
2. 生成 1~3 个标签，每个标签 2~4 个字，简短、语义清晰。
3. 标签优先复用下面已有的标签列表（如有），避免含义重复的新标签。

已有标签列表：{existingTags}

请只输出 JSON，格式如下：
{"title": "标题", "tags": ["标签1", "标签2"]}
```

**（2）思维方式总结（默认模板，可在设置里自定义）**
```
你是一名提示词分析专家。请分析下面这条提示词正文，总结它所体现的「思维方式」，包括：
1. 它采用了什么方法或框架（如角色扮演、分步拆解、示例引导、约束设定等）。
2. 它的结构逻辑（先做什么、后做什么）。
3. 它值得借鉴的技巧或思路。

请用简洁的中文输出，100~200 字，直接给出总结，不要复述原文。

提示词正文：
{body}
```

## 7. 存储与密钥

- 卡片数据与设置均存 **localStorage**（键如 `prompt-manager:cards`、`prompt-manager:settings`）。
- 密钥存 `.env.local`：`DEEPSEEK_API_KEY=sk-...`，**不提交**到版本库（`.env.local` 加入 `.gitignore`）。
- **注意**：localStorage 通常有约 5MB 上限；版本历史（每卡最多 10 条正文快照）会放大体积。v1 足够个人使用，若未来卡多可迁移 IndexedDB。
